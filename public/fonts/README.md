# Fonts Directory

Place the Cabinet Grotesk font files here.

## Required file:
- `CabinetGrotesk-Variable.woff2`

## How to get it:
1. Visit https://www.fontshare.com/fonts/cabinet-grotesk
2. Click "Download" → download the zip
3. Extract and find `CabinetGrotesk-Variable.woff2`
4. Place it in this `/public/fonts/` folder

The font is referenced in `src/app/globals.css` via:
```css
src: url('/fonts/CabinetGrotesk-Variable.woff2') format('woff2');
```
